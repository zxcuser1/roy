# SwarmLab2 — 3D swarm simulation

Практическая часть лабораторной работы 2: развитие лабораторной работы 1 из двумерного пространства в трёхмерное.

## Что изменено относительно ЛР1

- `Vector2` заменён на `System.Numerics.Vector3`.
- Положение, скорость, цель и силы теперь имеют координаты `X`, `Y`, `Z`.
- Мир ограничен параллелепипедом `120 × 80 × 60`.
- Препятствия имеют объём (`BoxObstacle`), а не являются плоскими прямоугольниками.
- Агент может обходить препятствие по X/Y или менять высоту по Z.
- Сохранены роевая составляющая, движение к цели, разделение агентов и обход препятствий.
- Добавлен механизм выхода из локального застревания.
- После достижения цели агент помечается завершившим маршрут и перестаёт отображаться.
- Добавлена 3D-визуализация с вращением, панорамированием и масштабированием камеры.
- Отображается история траектории агентов.

## Требования

- .NET SDK 9.0.100 или более новая версия 9.0.x.
- Avalonia 11.3.22 загружается через NuGet при `dotnet restore`.

Проверить SDK:

```bash
dotnet --list-sdks
```

## Запуск

Из корня проекта:

```bash
dotnet restore
dotnet build
dotnet run --project SwarmLab2.Desktop
```

## Управление

- ЛКМ + движение мыши — вращение сцены.
- ПКМ + движение мыши — сдвиг сцены.
- Колесо мыши — масштаб.
- `Пауза / Продолжить` — остановить/возобновить моделирование.
- `Перезапустить` — создать агентов заново с выбранным количеством.
- `Сбросить камеру` — вернуть исходный ракурс.

## Что происходит в алгоритме

Для каждого активного агента на каждом шаге рассчитывается новая скорость. На неё влияют:

1. инерция текущего движения;
2. направление к целевой точке;
3. персонально лучшая позиция агента;
4. положение лучшего агента роя;
5. сила разделения с соседями;
6. отталкивание и прогнозирование столкновения с 3D-препятствиями;
7. отталкивание от границ пространства;
8. дополнительное направление выхода, если агент долго не приближается к цели.

После вычисления скорости проверяются столкновения с объёмными препятствиями и границами мира. При попадании в радиус цели агент получает `ReachedTarget = true`, его скорость обнуляется, и `SimulationView` больше его не рисует.

## Что показать преподавателю

1. Координаты агента теперь трёхмерные (`Vector3`).
2. На сцене видна ось высоты Z и объёмные препятствия.
3. При вращении камеры видно, что агенты имеют разную высоту и реально движутся в 3D.
4. Рой обходит препятствия, в том числе сверху.
5. Агенты не накладываются полностью друг на друга благодаря `ComputeSeparation`.
6. При долгом отсутствии прогресса включается `EscapeDirection`, поэтому рой не должен намертво застревать у препятствия.
7. По достижении цели агент исчезает, а счётчик `Достигли цели` увеличивается.
