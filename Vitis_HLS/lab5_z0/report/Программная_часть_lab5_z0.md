# Программная часть lab5_z0

Задача: сравнить вычисления `lab5_z0` на одном ядре CPU, в многопоточной программе OpenMP и с оценкой аппаратной реализации FPGA из Vitis HLS.

## Вычисление

Используются четыре функции с простыми массивами `int`:
1. `func1`: `prod[i] = A[i] * B[i]`, `sum[i] = A[i] + B[i]`.
2. `func2`: `prod2[i] = 2 * prod[i]`.
3. `func3`: `sum2[i] = sum[i] * sum[i]`.
4. `func4`: `RES[i] = sum2[i] - prod2[i]`.

Результат проверяется независимо по `A[i]*A[i]+B[i]*B[i]`. Для предотвращения переполнения `int` исходные элементы имеют диапазон -500..500.

## Однопоточная реализация

`src/sw/lab5_z0_single.cpp`: в каждой функции обычный цикл `for`.

```cpp
void func2(const int prod[], int prod2[], int rows)
{
    for (int i = 0; i < rows; ++i)
        prod2[i] = 2 * prod[i];
}
```

## Многопоточная реализация

`src/sw/lab5_z0_openmp.cpp`: перед соответствующим циклом добавляется директива OpenMP.

```cpp
void func2(const int prod[], int prod2[], int rows)
{
#pragma omp parallel for
    for (int i = 0; i < rows; ++i)
        prod2[i] = 2 * prod[i];
}
```

Итерации записывают элементы с разными индексами, поэтому дополнительная блокировка при записи не требуется.

## Тестирование и замер

Тест `src/sw/lab5_z0_tb_sw.cpp` проверяет `ROWS = 8192, 32768, 131072, 524288, 2097152`. Для каждого размера запускает `lab5_z0` 33 раза. Время замеряется `std::chrono::steady_clock` только вокруг вызовов функции. Выделение памяти, генерация входных значений и проверка результата не входят в измеряемый участок. Вывод CSV: размер, режим, число потоков, число запусков, суммарное время, среднее время, контрольная сумма.

## Вывод

OpenMP распараллеливает независимые итерации между потоками CPU. FPGA использует аппаратный параллелизм (UNROLL/PIPELINE/DATAFLOW). При малых массивах расходы на организацию потоков могут превышать выигрыш. Для объективного end-to-end сравнения необходимо учитывать обмен данными с FPGA. Полные исходники обеих версий и тест лежат рядом в `src/sw/`.
