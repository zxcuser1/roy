# Vitis HLS lab4_z0 — программы для сравнения CPU и FPGA

Две 64-разрядные программы Windows для программной части лабораторной:

- `bin/lab4_z0_single.exe` — один поток.
- `bin/lab4_z0_openmp.exe` — реализация с `#pragma omp parallel for`.

Используется поэлементное умножение массивов `out_RES[i] = in_A[i] * in_B[i]`.
Время измеряется **только вокруг вызова функции**, 33 раза с помощью `std::chrono::steady_clock`.
Итоговое значение — **медиана** 33 измерений. Результаты сравниваются с эталоном (проверка не входит в измерение).

## Как запустить

На Windows 10/11 x64 откройте PowerShell/CMD в этой папке:

```bat
bin\lab4_z0_single.exe 8192
bin\lab4_z0_openmp.exe 8192
```

После вывода результата программа ожидает нажатия любой клавиши. Для отключения ожидания добавьте `--no-pause`.
Аргумент — количество элементов (`ROWS`), по умолчанию 8192.

Для исследования используйте размеры: `8192`, `32768`, `131072`, `524288`, `2097152`.
Можно запустить все эксперименты из командной строки с помощью `run_all.bat`.

В отчёт переносится строка `Median function time` (в `ns`; для мс делите на 1 000 000).
Не подставляйте времена из GitHub Actions: измеряйте на **своём ПК** и укажите характеристики именно этого ПК.

## Сборка из исходников

Исходные файлы находятся в `src/`. Бинарники собираются из одного и того же алгоритма с разными настройками.
GitHub Actions собирает статически скомпонованные Win64 EXE с GCC/MSYS2:

```bash
g++ -O2 -std=c++17 -static -static-libgcc -static-libstdc++ src/lab4_z0.cpp src/lab4_z0_tb.cpp -o bin/lab4_z0_single.exe
g++ -O2 -std=c++17 -static -static-libgcc -static-libstdc++ -fopenmp -DUSE_OPENMP src/lab4_z0.cpp src/lab4_z0_tb.cpp -o bin/lab4_z0_openmp.exe
```

Сравниваем одинаковую арифметику и те же данные, но разные варианты параллелизма. `-O2` применён в обоих случаях.
Это **программы для CPU-бенчмарка**, а не бинарники, синтезируемые для FPGA.
